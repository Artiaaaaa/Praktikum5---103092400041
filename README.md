1.	Pengertian Bootstrap [10 poin]
Bootstrap adalah framework CSS yang digunakan untuk mempermudah pembuatan tampilan website agar lebih menarik, rapi, dan responsif. Bootstrap menyediakan komponen siap pakai seperti tombol, form, navbar, card, dan sistem grid sehingga developer tidak perlu membuat semua desain dari awal. Kegunaan Bootstrap adalah mempercepat proses pembuatan website, mempermudah pengaturan tampilan, dan membuat website menyesuaikan ukuran layar perangkat seperti komputer, tablet, dan HP.

2.	Memasang Bootstrap [10 poin]
  a. Buka VS Code dan buat file HTML, misalnya index.html.
  b. Buat struktur dasar HTML.
  c. Tambahkan link Bootstrap di dalam tag <head> seperti berikut:
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
    
3.	Grid dan Breakpoint [10 poin]
Grid adalah sistem tata letak Bootstrap yang digunakan untuk mengatur posisi dan lebar elemen website berdasarkan baris (row) dan kolom (column). Bootstrap menggunakan sistem 12 kolom untuk membantu membagi ruang halaman. Breakpoint adalah batas ukuran layar yang digunakan untuk mengubah tata letak website sesuai perangkat yang digunakan.

4.	Class Bootstrap [10 poin]
  a.	Container : Membuat wadah konten dengan lebar yang menyesuaikan ukuran layar.
  b.	Row : Membuat baris untuk menyusun kolom dengan sistem grid.
  c.	Col : Membuat kolom dalam sistem grid.
  d.	btn : Memberikan tampilan dasar pada tombol.
  e.	btn-primary : Memberikan warna utama pada tombol.

5.	Gambar Responsif [10 poin]
Bagaimana cara agar foto atau gambar pada website responsif menyesuaikan ukuran layar perangkat?
Jawab:
Agar gambar pada website responsif dan menyesuaikan ukuran layar perangkat,  maka memakai class img-fluid pada elemen <img>. Class img-fluid menerapkan max-width: 100% dan height: auto, sehingga gambar tidak melebihi lebar wadahnya dan rasio gambar tetap terjaga ketika ukuran layar berubah.
